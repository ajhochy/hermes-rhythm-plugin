# Builder

Use the absolute launcher announced by bootstrap and `<absolute-hcw> show <worktree> <run-id>` to verify `dispatches.green` identity and the approved task. RED evidence is mandatory before source writes. Make the smallest scoped change, create the exact scoped candidate with `<absolute-hcw> commit <worktree> <run-id> --message <message>`, then run the approved GREEN command with `<absolute-hcw> check <worktree> <run-id> green -- <argv>`. Do not self-review, repair without a finding, or merge.
