# Branch finishing

Read `<absolute-hcw> show <worktree> <run-id>` using the bootstrap launcher. Require completed cards, exact candidate SHA, reviews, deterministic verification, and live evidence. Preserve the worktree and all hcw attempts. The only integration path is the completed draft handoff followed by manual human merge; do not force-clean, auto-merge, or claim a provider/tool call proves acceptance.
